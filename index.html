Everything in one player

Built for everyday playback

PyPlay keeps the surface simple while providing the controls and persistence features that make a desktop player useful.

▶

Wide format support

Play common video and audio formats through the libVLC playback engine.

⌁

Precision seeking

Click a target time or drag the timeline handle with live time feedback.

▤

Playlist workflow

Add individual files or folders and manage playback from the dedicated Playlist view.

◷

Recent and resume

Reopen recent media and continue unfinished playback from its saved position.

♫

Audio and subtitles

Select available tracks and load external subtitle files from the upper menus.

↗

Fullscreen control

Toggle fullscreen with the button, double-click, the F key, or Escape to exit.

◒

Persistent settings

Remember volume, speed, seek interval, resume behavior, subtitles, and interface preferences.

!

Clear diagnostics

Get clearer VLC and playback errors plus startup diagnostics when something goes wrong.

◎

Interactive idle screen

Click the logo or drag media onto it to begin playback immediately.

Developer setup · PowerShell
# Clone the repository
git clone https://github.com/AmiNilay/PyPlay.git
cd PyPlay

# Create and activate a virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1

# Install dependencies and run
python -m pip install -r requirements.txt
python main.py
