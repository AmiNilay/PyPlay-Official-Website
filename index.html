PyPlay Media Player

A sleek, feature-rich desktop media player built with Python & libVLC.

⬇ Download PyPlay v1.0 🐙 View on GitHub ⭐
🪟 Windows 64-bit (.zip ) 📦 v1.0 (Latest) 🛡️ 100% Free & Open Source

Key Features

🎬

Wide Format Support

Plays MP4, MKV, AVI, MP3, FLAC, AAC powered by the robust libVLC engine.

📑

Smart Playlists

Load single files or queue entire folders effortlessly with drag-and-drop support.

⚡

Precision Playback

Variable playback speed (0.5x to 2.0x) with seamless frame seeking.

🔊

Smart Controls

Mouse-wheel volume control, quick mute toggles, and intuitive keyboard hotkeys.

🔲

Immersive Fullscreen

Native fullscreen mode with intelligent auto-hiding playback controls.

💬

Subtitle Support

Automatic loading and manual synchronization for external `.srt` and `.vtt` files.

📸

Instant Snapshots

One-click high-resolution frame capture saved directly to your local disk.

Installation Guide

For standard users, simply download the .zip from the hero section, extract, and run PyPlay.exe (Requires VLC installed). For developers, run from source using the steps below:

bash - Developer Setup
# 1. Clone & enter directory git clone https://github.com/AmiNilay/PyPlay.git && cd PyPlay # 2. Activate virtual environment python -m venv venv && source venv/bin/activate # Windows: venv\Scripts\activate # 3. Install dependencies & run pip install -r requirements.txt python main.py
